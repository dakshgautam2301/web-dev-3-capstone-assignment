# Online Examination and Assessment Management System

A backend REST API for managing online examinations, students, faculty, question banks, exam attempts, automatic evaluation, results, and dashboard analytics.

## Features

- User registration and login
- JWT access and refresh token authentication
- Role-based access control (Admin, Faculty, Student)
- Password hashing using bcrypt
- Question bank management (CRUD)
- Examination management (CRUD)
- Student examination attempts and submissions
- Automatic evaluation and result generation
- Dashboard statistics and subject-wise performance analytics
- MongoDB database with Mongoose
- Centralized error handling and validation
- Socket.IO real-time event integration
- EventEmitter-based event handling
- MongoDB indexing and aggregation pipelines

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JSON Web Token (JWT)
- bcrypt
- Socket.IO
- Postman
